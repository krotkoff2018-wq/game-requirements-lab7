# Требования игр к ресурсам ПК и ноутбуков

Учебный сайт лабораторной работы №7 по дисциплине «Нейронные сети».

Одностраничный сайт содержит пояснения о комплектующих, четыре профиля требований Cyberpunk 2077 и Baldur’s Gate 3, проверку введённой конфигурации и сохранение результата в TXT. Есть три учебных примера, подсветка изменений и адаптивный макет.

## Открытие

Откройте `index.html` в современном браузере с JavaScript. Изображения, стили и код встроены в файл; для самой страницы интернет не нужен. Внешние источники открываются при подключении к интернету.

## Правила проверки

Память, свободное место и SSD проверяются независимо. CPU/GPU настольного ПК сравниваются с эталонами выбранного профиля либо подтверждаются пользователем. Для неизвестных моделей и ноутбуков нужна отдельная оценка. Сайт не определяет оборудование и не рассчитывает FPS.

## Проверки

Пройдены 18 автоматических тестов и 14 сценариев интерфейса. В одном из тестов 84 сценария сравнены с Python-программой лабораторной №6. Узкий макет проверен в рамке шириной 390 CSS пикселей.

Данные требований сверены 25.10.2026. Иллюстрации сгенерированы в лабораторной работе №3 и не являются доказательством производительности оборудования.
